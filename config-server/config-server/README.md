# Healthcare EMR - Config Server

This is Step 2 of the Enterprise Healthcare EMR & Appointment Ecosystem.

## Technology
- Java 21
- Spring Boot 3.5.6
- Spring Cloud 2025.0.0
- Maven
- Spring Cloud Config Server

## Run
Run:

ConfigServerApplication.java

Or:

mvn spring-boot:run

## Server
Config Server runs on:

http://localhost:8888

The project is configured to use a classpath-based native configuration location.
