# Healthcare EMR - API Gateway

This is Step 3 of the Enterprise Healthcare EMR & Appointment Ecosystem.

## Technology
- Java 21
- Spring Boot 3.5.6
- Spring Cloud 2025.0.0
- Spring Cloud Gateway
- Eureka Discovery Client
- Maven

## Port

API Gateway runs on:

http://localhost:8080

## Important

For this beginner/fresher step, no JWT filter or service routes are added yet.

After Eureka Server is running on port 8761, start this application.
It should register itself with Eureka.

## Run

Run:

ApiGatewayApplication.java

Or:

mvn spring-boot:run
